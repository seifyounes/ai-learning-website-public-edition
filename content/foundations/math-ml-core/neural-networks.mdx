**You need:** matrix-times-vector from → linear-algebra-for-ai and the gradient-descent loop
from → calculus-for-optimization. The memory maths is one multiplication.

Strip the mystique: a neural network is **matrix multiplies separated by simple nonlinear
functions**, trained by gradient descent. What makes it worth a lesson is the *systems
consequences*: where the gigabytes, the milliseconds and the dollars come from.

## The unit: matmul + nonlinearity

One layer: `output = activation(W·x + b)`. The matrix W holds the learned numbers; the
**activation** (ReLU and friends) bends the output so stacked layers don't collapse into one
linear map. Stack dozens to hundreds of these and you have every network in production,
including the transformer blocks inside every LLM you call.

## Worked example: one layer by hand, then a sizing call

**The forward pass.** Input x = (1, 2). Weights W has rows (1, −1) and (0.5, 0.5); bias
b = (0, 1). Activation: ReLU, which turns negatives into 0.

1. **Multiply:** W·x = (1×1 + (−1)×2, 0.5×1 + 0.5×2) = (−1, 1.5).
2. **Add the bias:** (−1, 1.5) + (0, 1) = (−1, 2.5).
3. **Bend:** ReLU(−1, 2.5) = **(0, 2.5)**.

Step 3 is the whole point. Without it, a second layer W₂ would compute W₂(W·x), which equals
(W₂W)·x: one matrix again. A model is billions of these three steps.

**The sizing call.** You want an 8B model on a laptop with a 16 GB GPU.

1. **fp16:** 8B × 2 bytes = 16 GB. It doesn't fit: nothing is left for the context.
2. **8-bit:** 8B × 1 byte = 8 GB. Fits, with room for a decent context.
3. **4-bit:** 8B × 0.5 bytes = 4 GB (real files run a little larger). Fits easily, at a small
   quality cost you should test on your own tasks.

Pick 8-bit if quality matters most, 4-bit if you want long contexts or a second model loaded.

## Depth = hierarchy

Early layers detect simple patterns; later layers compose them into abstractions. Composition
is the superpower: features learned once get reused by everything above them. That's why
"deep" beats "wide", and why early layers of a language model tend to handle surface patterns
such as spelling while later layers track meaning.

> try to fit it with zero hidden layers — then add two. Watch the decision boundary go from a
> straight line to a spiral. That's the entire "why depth" argument in 60 seconds.

## Where the memory goes (the money question)

- **Inference:** weights ≈ params × bytes/param. 7B fp16 ≈ 14 GB; 4-bit ≈ 3.5 GB.
  Quantization = fewer bytes per parameter, the trick that put real models on laptops.
- **Training:** weights + gradients + optimizer state + activations: several times more (about
  4× if everything is stored at the same precision, more with mixed-precision copies, before
  activations). That's why full fine-tunes need big GPUs while LoRA runs on one card.
- **Speed:** every generated token flows through every layer's matmuls. Bigger model → more
  FLOPs → more latency → higher price per token. Model tiers ARE network sizes.

## Parameters learn; activations flow

Two memories people confuse: **parameters** (the learned weights, fixed at inference) and
**activations** (the per-request values flowing through, alive only during a pass). The
KV cache (→ transformers-attention) is activation-side: it scales with YOUR prompt and output
length, not with model size alone.

## Common failure modes

- **A local model loads but runs painfully slowly** → it didn't fit in GPU memory and spilled
  into system RAM → pick a smaller quantization or a smaller model.
- **Out of memory only on long prompts** → the KV cache grows with context → lower the context
  setting or leave headroom when you size the model.
- **A fine-tune OOMs where chat ran fine** → training's memory multiplier → LoRA or QLoRA,
  gradient checkpointing, or a smaller batch.
- **Answers get noticeably worse after quantizing** → too few bits per weight for your task →
  step back up to 4-bit or 8-bit and compare on your own examples.

## Why this pillar exists

You'll never hand-code a layer, but every sizing, pricing, latency and local-vs-API decision
you make is this lesson's arithmetic. "7B at 4-bit fits my laptop" is a sentence that closes
architecture debates, and now you can derive it, not just repeat it.
