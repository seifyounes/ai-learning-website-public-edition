task: |
  Compute dot products three ways, then build a tiny attention score table.

  **In Python (20 minutes, free Google Colab works).**

  ```python
  import numpy as np

  def dot(u, v):
      return sum(a * b for a, b in zip(u, v))

  v, w = np.array([1.0, 2.0]), np.array([3.0, 4.0])
  print("by hand:", dot(v, w), " numpy:", v @ w)
  proj = (v @ w) / np.linalg.norm(v)              # length of w's shadow on v
  print("projection x length:", proj * np.linalg.norm(v))

  q = np.array([1.0, 0.0, 2.0])
  K = np.array([[2.0, 1.0, 1.0], [0.0, 3.0, -1.0], [1.0, 1.0, 1.0]])
  scores = K @ q                                   # one dot product per key
  weights = np.exp(scores) / np.exp(scores).sum()  # softmax
  print("scores:", scores, " weights:", weights.round(3))

  Q = np.random.randn(5, 3)
  S = Q @ K.T                                      # a 5 x 3 table of dot products
  print(np.isclose(S[2, 1], dot(Q[2], K[1])))      # True
  ```

  Then double the length of the second key (multiply that row of K by 2), rerun, and write one
  line on what happened to its score and its weight.

  **No code?** In a spreadsheet, put q in one row and each key in the rows below, and compute
  each score with `=SUMPRODUCT(...)`. Check that you get 4, −2 and 3.

  Success: all three methods give 11; the scores are 4, −2 and 3; and you can say why a longer
  key changes its score.

The dot product is the single operation most of modern AI leans on. Similarity search, attention
scores, a neuron's input, a model's next-token scores: each one is a dot product, or a big table
of them computed as a matrix product. This lesson gives you the two ways to read it: as
**alignment**, and as a **vector acting like a function**.

## The rule and the picture

**The rule:** pair up the coordinates of two same-length vectors, multiply each pair, add.
(1, 2)·(3, 4) = 1·3 + 2·4 = 11.

**The picture:** project one vector onto the line through the other, then multiply the length of
that shadow by the length of the vector you projected onto. That gives three cases:

- **Positive** when the two point roughly the same way.
- **Zero** when they're perpendicular.
- **Negative** when they point roughly opposite ways.

The order doesn't matter: v·w = w·v. And scaling either vector scales the dot product by the
same factor, so a longer vector gets bigger scores in both directions.

## Duality: a vector is a function

A linear function that turns a vector into a single number is recorded, like any linear map, by
where the basis vectors land. Each lands on one number, so the matrix is 1 × n, which is just
a vector tipped on its side. Applying it is a dot product.

So **every linear function from vectors to a single number is a dot product with one specific
vector**, and every vector defines such a function. Reading a vector this way is what makes
neurons readable: a neuron's weight vector is a fixed direction that asks "how much does the
input point my way?"

## Worked example: three attention scores

A query and three keys, each in three dimensions: q = (1, 0, 2), k₁ = (2, 1, 1),
k₂ = (0, 3, −1), k₃ = (1, 1, 1).

1. **Scores.** q·k₁ = 2 + 0 + 2 = **4**. q·k₂ = 0 + 0 − 2 = **−2**. q·k₃ = 1 + 0 + 2 = **3**.
2. **Softmax** turns scores into weights that sum to 1: e⁴ ≈ 54.6, e⁻² ≈ 0.14, e³ ≈ 20.1, total
   ≈ 74.8, so the weights are about **0.73, 0.002 and 0.27**.

Key 1 aligns best with the query and gets most of the attention; key 2 points partly away and
gets almost none. Real attention also divides scores by the square root of the vector width
before the softmax (→ transformers-attention).

Stacking queries as rows of Q and keys as rows of K, the whole table of scores is one product:
**QKᵀ**, where entry (i, j) is query i dotted with key j. For n tokens that table is n × n. At
1,000 tokens it holds a million scores per attention head per layer; at 2,000, four million.

## Common mistakes

- **Reading zero as "no weight".** A zero score is a middle value; softmax still gives it a
  share.
- **Ranking by raw dot product without thinking about length.** Longer vectors score higher
  against everything; dividing out the lengths gives cosine similarity
  (→ cosine-similarity-search).
- **Assuming attention cost grows linearly.** The score table is n × n, so doubling a prompt
  roughly quadruples it. Trim, summarize or retrieve instead of pasting everything.
- **Mixing up the dot product with entry-by-entry multiplication.** The dot product adds the
  products into one number.

## Where you'll see it in AI

- **Attention scores** are query-key dot products (→ transformers-attention).
- **Neurons and linear probes** are dot products with learned weight vectors (→ neural-networks).
- **Next-token scores:** the output head dots the final hidden vector with one row per token in
  the vocabulary.
- **Similarity search** ranks by normalized dot products (→ cosine-similarity-search).
