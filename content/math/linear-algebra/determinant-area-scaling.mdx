  **On paper (10 minutes).** For each matrix (given as its two columns), compute ad − bc, then
  sketch what happens to the unit square:

  1. Columns (3, 1) and (1, 2).
  2. The same columns swapped: (1, 2) and (3, 1).

  **In Python (15 minutes, free Google Colab works).**

  ```python
  import numpy as np

  A = np.array([[3, 1], [1, 2]])
  B = np.array([[2, 0], [0, 0.5]])
  print(np.linalg.det(A), np.linalg.det(B), np.linalg.det(A @ B))

  # A perfectly invertible matrix with a "tiny" determinant.
  S = 0.5 * np.eye(1000)
  print("det:", np.linalg.det(S))
  print("rank:", np.linalg.matrix_rank(S), "condition number:", np.linalg.cond(S))
  ```

A linear transformation stretches some regions and squashes others. The **determinant** is the
single number that says by how much. Its most useful value is zero: a zero determinant means the
transformation squashed space into fewer dimensions, so some information can never be
recovered. That's the idea behind "singular matrix" errors, and the stepping stone to inverses,
rank and eigenvalues.

## One number for every area

Take the unit square sitting on the two basis vectors and watch where a matrix sends it. A
matrix with columns (3, 0) and (0, 2) turns it into a 3 × 2 rectangle: area 6. A shear turns it
into a slanted parallelogram with the same base and height: area still 1.

Because grid lines stay parallel and evenly spaced, every grid square is scaled by the same
factor, and any shape can be approximated by small squares. So that one factor applies to every
region. That factor is the determinant. In three dimensions it scales volume instead: the unit
cube becomes a slanted box.

## Zero and negative values

- **Zero:** every area becomes zero, so the plane was squashed onto a line or a point (in 3D,
  onto a plane, line or point). This happens exactly when the matrix's columns are linearly
  dependent (→ span-and-basis-vectors).
- **Negative:** the transformation flips space over, like turning a sheet of paper. The size of
  the number is still the area factor; the sign records the flip.

## Worked example: three 2 × 2 matrices

For a matrix with columns (a, c) and (b, d), the determinant is **ad − bc**.

1. Columns (3, 1) and (1, 2): a = 3, c = 1, b = 1, d = 2, so 3·2 − 1·1 = **5**. Every area grows
   five times; a triangle of area 2 becomes area 10.
2. Swap the columns, (1, 2) and (3, 1): 1·1 − 3·2 = **−5**. Same area factor, but the basis
   vectors have swapped sides, so orientation flips.
3. Columns (2, 4) and (1, 2): 2·2 − 1·4 = **0**. The first column is twice the second, so the
   whole plane lands on one line.

One more property follows straight from the picture: applying A and then B scales areas by
det(A) and then by det(B), so **det(BA) = det(B)·det(A)**.

## Common mistakes

- **Using the determinant's size to judge "almost singular".** Halving each of 1,000 directions
  gives a determinant near 10⁻³⁰¹ for a perfectly invertible matrix. Use rank or the condition
  number instead.
- **Reading a negative determinant as shrinking.** The sign means a flip; the size means scaling.
- **Expecting determinants of non-square matrices.** They only exist for square ones (shape
  changes are in → nonsquare-matrices-dimensions).
- **Memorizing before understanding.** The formula is easy to look up; "area factor" is what you
  reason with.

## Where you'll see it in AI

- **Singular matrices in fitting:** dependent features make the matrix inside a least-squares fit
  have determinant 0 (→ machine-learning-fundamentals).
- **Probability densities:** the formula for a multivariate Gaussian includes the determinant
  of the covariance matrix, which measures how spread out the data is.
- **Normalizing flows:** these generative models track how a learned transformation stretches
  volume, using log-determinants, so probabilities stay correctly scaled.
- **Eigenvalues:** the determinant is the product of a matrix's eigenvalues
  (→ eigenvectors-eigenvalues).
