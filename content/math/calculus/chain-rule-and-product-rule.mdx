task: |
  **Get a neuron's gradient by the chain rule, then check it (25 minutes).**

  A one-input neuron predicts `p = sigmoid(w × x)` and its loss is `(p − y)²`. Take `w = 0.5`,
  `x = 2`, `y = 1`.

  1. On paper, write the chain: `w → z = w·x → p = sigmoid(z) → loss`. Write each link's local
     derivative: `dz/dw = x`, `dp/dz = p(1 − p)` (the sigmoid's derivative), `dloss/dp = 2(p − y)`.
  2. Compute the forward values (`z = 1`, `p ≈ 0.7311`), then multiply the three links.
  3. Check your answer with a nudge:

     ```python
     import math

     def loss(w, x=2.0, y=1.0):
         p = 1 / (1 + math.exp(-w * x))
         return (p - y) ** 2

     h = 1e-6
     print((loss(0.5 + h) - loss(0.5 - h)) / (2 * h))
     ```

  No Python? Use a spreadsheet with `=1/(1+EXP(-A1*2))` for p.

  Success: your chain-rule product is about −0.2115 (that's −0.5379 × 0.1966 × 2) and the nudge
  check prints the same value to four decimals.

**You need:** → derivative-rules-by-geometry (power rule, and that sin's derivative is cos).

The one idea of this lecture: **when one function sits inside another, a nudge to the input
passes through each step, and the final change is the product of the steps' local rates.**
That's the chain rule. A neural network is a long chain of simple functions, and
backpropagation is the chain rule applied from the loss back to every weight.

## Three ways to combine functions

- **Sum:** the change in `sin x + x²` is the change in `sin x` plus the change in `x²`. The
  derivative is `cos x + 2x`.
- **Product:** think of `sin x · x²` as the area of a box. A nudge adds a strip `sin x · d(x²)`
  along one side and `x² · d(sin x)` along the other; the corner is negligible. Derivative:
  `sin x · 2x + x² · cos x` ("left d-right plus right d-left").
- **Composition:** for `sin(x²)`, put three number lines in a row: `x`, then `h = x²`, then
  `sin(h)`. A nudge `dx` makes `dh ≈ 2x·dx`, which makes `d(sin h) ≈ cos(h)·dh`. Multiply:
  `cos(x²) · 2x`.

```diagram
x
│  × 2x
▼
h = x²
│  × cos(h)
▼
sin(h)
```

## Worked example with real numbers

**The lecture's function.** At `x = 1.5`: the inner value is `h = 2.25`, the inner rate is
`2 × 1.5 = 3`, and the outer rate is `cos(2.25) ≈ −0.628`. Chain rule:
`−0.628 × 3 ≈ −1.885`. A nudge check (x to 1.501) gives about −1.889, matching to two decimals.

**A one-weight model.** It predicts `w × x`; the loss is `(w·x − y)²`. One example: `x = 2`,
`y = 6` (so the best weight is 3).

1. Name the inside: `e = w·x − y`, the error. Then `loss = e²`.
2. Local rates: `dloss/de = 2e` (power rule) and `de/dw = x` (constant times w).
3. Multiply: `dloss/dw = 2e · x = 2(2w − 6) · 2 = 8w − 24`.

At `w = 1`: the error is −4 and the gradient is −16. Check with a nudge: at `w = 1.01` the loss
is `(2.02 − 6)² = 15.8404`, down 0.1596 from 16, a ratio of −15.96. The negative sign says
"raise w", which moves it toward 3. → calculus-for-optimization takes this exact gradient and
runs gradient descent with it.

## Common mistakes

- **Evaluating the outer derivative at x instead of the inner value.** It's `cos(x²)`, not
  `cos(x)`.
- **Dropping the inner factor.** `2(w·x − y)` alone forgets `× x`.
- **Multiplying derivatives for a product.** `(gh)'` is `g'h + gh'`, never `g'h'`.
- **Treating the rules as separate tricks.** Real expressions layer all three; peel them one
  layer at a time.

## Where you'll see it in AI

- **Backpropagation** is the chain rule run backwards through every layer, reusing the
  intermediate values (→ backprop-chain-rule-calculus).
- **Vanishing gradients:** rates multiply along the chain, so many factors below 1 shrink the
  gradient that reaches early layers (→ neural-networks).
- **Gated activations** like SiLU (`x · sigmoid(x)`) need the product rule; frameworks apply it
  automatically.
