The one idea of this lecture: **with several inputs, you take the derivative along one input at
a time, holding every other input fixed.** That's a partial derivative. A model's loss is a
function of all its weights at once, and training needs to know how the loss responds to each
weight separately. Each of those responses is a partial.

## The picture: nudge in one direction

For `f(x)`, a nudge `dx` moves the output by `df`, and the derivative is their ratio. For
`f(x, y)`, the inputs are points on a plane. A nudge purely in the x direction moves the output
by some amount; that ratio is `∂f/∂x` (read "partial f, partial x"). A nudge purely in the y
direction gives `∂f/∂y`. The curly `∂` is a reminder that each one tells only part of the story.

## How to compute one

Freeze the other inputs and take an ordinary derivative. For `f(x, y) = x²y + sin(y)`:

- **∂f/∂x:** treat y as a constant. `x²y` → `2xy`; `sin(y)` is a constant → 0. So `∂f/∂x = 2xy`.
- **∂f/∂y:** treat x as a constant. `x²y` → `x²`; `sin(y)` → `cos(y)`. So `∂f/∂y = x² + cos(y)`.

At (1, 2): `∂f/∂x = 4` and `∂f/∂y = 1 + cos(2) ≈ 0.584`. Moving in x changes this function about
seven times faster than moving in y, at this point.

## Worked example: a two-weight model

A model predicts `w1·x1 + w2·x2` and its loss on one example is `(prediction − y)²`. Take
`x1 = 1`, `x2 = 3`, `y = 10`, and start at `w1 = w2 = 1`. The prediction is 4 and the error
`e` is −6.

| partial | formula | value |
|---|---|---|
| ∂loss/∂w1 | 2e · x1 | −12 |
| ∂loss/∂w2 | 2e · x2 | −36 |

Both are negative, so raising either weight lowers the loss. The second weight's effect is three
times larger simply because its feature is three times larger. Now measure `x2` in different
units, 300 instead of 3, and set `w2 = 0.01` so the prediction is still 4. The error is still
−6, the first partial is still −12, but the second becomes `2 × (−6) × 300 = −3,600`. That's why
practitioners rescale features before training: one learning rate can't suit two partials a
hundred times apart.

## Common mistakes

- **Moving two inputs at once.** Then you've measured a combined change, not a partial.
- **Differentiating the frozen variable.** In `∂/∂y`, `x²` is a constant, not `2x`.
- **Reading a partial as a value.** `∂L/∂w2 = −36` says how sensitive the loss is to w2, not how
  big w2 is.
- **Forgetting that partials depend on the point.** Recompute them after every change; 2xy is
  different everywhere.

## Where you'll see it in AI

- **Training:** a network with a million weights has a million partials of the loss, one per
  weight (→ gradient-vector-of-partials packs them into one vector).
- **Feature scaling:** unscaled features give partials of wildly different sizes, which slows
  gradient descent (→ calculus-for-optimization).
- **Backprop** computes all these partials efficiently with the chain rule
  (→ backprop-chain-rule-calculus).
