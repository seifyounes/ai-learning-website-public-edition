  ```python
  import numpy as np

  tokens = ["Snape", "Lupin", "Quirrell", "banana"]
  logits = np.array([4.0, 2.5, 2.0, -1.0])

  def softmax(z, T=1.0):
      e = np.exp((z - z.max()) / T)
      return e / e.sum()
  ```

model as a next-word predictor (→ llm-next-word-prediction). No new maths beyond those.

A transformer turns text into a probability for every possible next token, and almost all of
the work is **matrices of learned weights multiplying vectors of data**. This lesson follows
one prompt from start to finish so that every later lesson in the track has a place to land:
attention, the MLP layers, the code and the KV cache are each one box of this pipeline.

## The pipeline in one paragraph

Your prompt becomes **tokens** (words, pieces of words, punctuation), and each token becomes
an **embedding vector**. The vectors flow through N identical **blocks**. Each block has an
**attention** step where vectors exchange information (→ query-key-value-attention), then an
**MLP** where each vector is transformed on its own (→ mlp-layers-store-facts). The last vector
is **unembedded** into one score per vocabulary token, the **logits**, softmaxed into a
distribution, and a token is sampled. Append it and run again.

```diagram
prompt text
   │
   ▼
tokens
   │ × W_E (embedding)
   ▼
vectors, one per token
   │
   ▼
[attention → MLP] × N
   │
   ▼
last vector
   │ × W_U (unembedding)
   ▼
logits, one per token
   │ softmax(logits / T)
   ▼
probabilities → sample
```

## Embeddings: meaning as direction

The **embedding matrix** W_E has one column per token in the vocabulary. In GPT-3 that's 50,257
tokens, each with a 12,288-number vector. The values start random and are learned, and
training tends to make **directions** meaningful: the difference between "woman" and "man" is
roughly the difference between "queen" and "king". The **dot product** measures how well two
vectors align: positive when they point the same way, zero when perpendicular, negative when
opposed. That one operation is the heart of attention in the next lesson.

The model also has a **context size**, the fixed number of vectors it processes at once
(2,048 for GPT-3). Text outside that window can't affect the prediction.

## Worked example: logits, softmax and temperature

Suppose the last vector, multiplied by the unembedding matrix, gives logits 2, 1 and 0 for
three candidate tokens. Softmax raises e to each value and divides by the total. Dividing
the logits by a **temperature** T first changes the spread:

| T | token A | token B | token C |
|---|---|---|---|
| 0.5 | 0.867 | 0.117 | 0.016 |
| 1 | 0.665 | 0.245 | 0.090 |
| 2 | 0.506 | 0.307 | 0.186 |

At T = 1: e² ≈ 7.39, e¹ ≈ 2.72, e⁰ = 1; total 11.11, so 7.39 / 11.11 ≈ 0.665. Halving T makes
the leader dominate; doubling it gives the third token twice the chance. At T = 0 the top token
always wins.

And the parameter count: W_E is 50,257 × 12,288 ≈ **617 million** weights, and the
unembedding W_U has the same shape transposed, so together about **1.24 billion**, under 1% of
GPT-3's 175 billion. The rest sits in the attention and MLP blocks.

## Common mistakes

- **Thinking tokens are words.** They're often pieces of words; counts and costs are in tokens.
- **Reading temperature 0 as certainty.** It's a decoding rule that always takes the top token.
- **Thinking the embedding is the final meaning.** It's only the starting point; the blocks pull
  each vector toward a meaning that fits its context.
- **Forgetting the window.** Whatever falls outside the context size has no effect.
