task: |
  Compute one attention head by hand, then check it with code.

  Three tokens, "fluffy", "blue", "creature", with 2-number keys, values and a query for
  "creature":

  - keys: fluffy [2, 0], blue [1, 1], creature [0, 0.5]
  - values: fluffy [1, 0], blue [0, 1], creature [0, 0]
  - query of "creature": [1, 1]

  On paper: compute the three dot products, divide by √2, softmax, and blend the values. Then
  repeat for "fluffy" with query [0, 1], applying the causal mask (it can only see itself).

  ```python
  import numpy as np

  K = np.array([[2, 0], [1, 1], [0, 0.5]])
  V = np.array([[1, 0], [0, 1], [0, 0]])
  q = np.array([1, 1])

  scores = K @ q / np.sqrt(K.shape[1])
  weights = np.exp(scores) / np.exp(scores).sum()
  print("weights:", weights.round(3))
  print("output:", (weights @ V).round(3))
  ```

  Then change the key of "creature" to [3, 3] and predict, before running, what happens to
  the weights.

  Success: your hand numbers match the code to two decimals, and your prediction for the
  changed key was right.

Attention is how a token's vector gets updated by the other tokens around it. A word like
"bank" enters the model with one embedding whatever it means; after attention, the vector for
"bank" in "river bank" has moved toward a different meaning than in "bank loan". Every
language model you call does this in every layer, so this is the single most important
mechanism in the track.

## The three projections

Each token's embedding is multiplied by three learned matrices:

- **Query** (W_Q): what this token is looking for.
- **Key** (W_K): what this token offers to others that are looking.
- **Value** (W_V): what this token will pass along if it's chosen.

Queries and keys live in a small space (much smaller than the embedding), and how well a query
matches a key is their **dot product** (→ dot-product-duality). Every query is compared with
every key, giving an n × n grid of scores for n tokens.

```diagram
token vectors x1 … xn
   │
   │  × W_Q → Queries Q
   │  × W_K → Keys K
   │  × W_V → Values V
   ▼
scores = Q·Kᵀ / √d
   n × n: every token
   against every token
   │
   ▼
causal mask
   hides later tokens
   │
   ▼
softmax → weights
   each row sums to 1
   │
   ▼
weights × V
   each token gets a blend
   of the Values it matched
```

Three details matter. The scores are **divided by √d** (d is the key size) so they don't grow
with the vector length and push softmax into all-or-nothing weights. In a language model,
**the causal mask** sets every score where a token would look at a later token to minus
infinity, so softmax gives it weight zero. And the blended value is **added** to the token's
embedding: attention nudges vectors, it doesn't replace them.

## Worked example: one head, by hand

"fluffy blue creature", keys of size 2. The query of "creature" is [1, 1]; the keys are
fluffy [2, 0], blue [1, 1], creature [0, 0.5].

1. **Dot products:** 2, 2 and 0.5.
2. **Scale by √2 ≈ 1.414:** 1.414, 1.414, 0.354.
3. **Softmax:** e^1.414 ≈ 4.11, e^1.414 ≈ 4.11, e^0.354 ≈ 1.42; total 9.65, so the weights
   are **0.43, 0.43, 0.15**.
4. **Blend values** fluffy [1, 0], blue [0, 1], creature [0, 0]:
   0.43·[1, 0] + 0.43·[0, 1] = **[0.43, 0.43]**, added to the embedding of "creature".

"creature" now carries some "fluffy" and some "blue". For "fluffy", the first token, the mask
leaves only itself, so its weight on itself is 1.

## Many heads, and the cost

One head learns one kind of lookup. A layer runs many heads in parallel, each with its own
matrices, and adds their outputs. In GPT-3, one head has about 6.3 million parameters; 96 heads
per block make about 600 million, and 96 blocks just under 58 billion, only about a third of
the model. Because every head builds an n × n grid, doubling the context roughly
**quadruples** the attention work, which is why long contexts cost more.

## Common mistakes

- **Mixing up who asks.** The token being updated sends the query; the others offer keys.
- **Thinking the nearest word wins.** Position matters only through what the embeddings carry;
  a word far away can get the top weight.
- **Forgetting that the output is added.** The token keeps its own meaning plus a
  context-weighted adjustment.
- **Picturing one head as "the" attention.** Real layers run dozens of heads, and models stack
  dozens of layers.
