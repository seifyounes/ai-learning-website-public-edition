task: |
  Rebuild the lecture's attention steps in NumPy, one version at a time, and check they agree.

  ```python
  import numpy as np

  rng = np.random.default_rng(1337)
  T, C, H = 4, 8, 16          # tokens, channels, head size
  x = rng.normal(size=(T, C))

  # Version 1: loop average of the past
  v1 = np.array([x[: t + 1].mean(axis=0) for t in range(T)])

  # Version 2: lower-triangular matrix, rows normalized
  tril = np.tril(np.ones((T, T)))
  v2 = (tril / tril.sum(axis=1, keepdims=True)) @ x

  # Version 3: softmax over a masked grid of zeros
  def masked_softmax(s):
      s = np.where(tril == 0, -np.inf, s)
      e = np.exp(s - s.max(axis=1, keepdims=True))
      return e / e.sum(axis=1, keepdims=True)
  v3 = masked_softmax(np.zeros((T, T))) @ x

  print(np.allclose(v1, v2), np.allclose(v2, v3))

  # Version 4: one self-attention head
  Wq, Wk, Wv = (rng.normal(size=(C, H)) / np.sqrt(C) for _ in range(3))
  q, k, v = x @ Wq, x @ Wk, x @ Wv
  wei = masked_softmax(q @ k.T * H ** -0.5)
  print(wei.round(2))
  out = wei @ v
  print(out.shape)
  ```

The earlier lessons drew a transformer; this one writes it. The single idea that makes the
code short: **self-attention is a weighted average of past tokens, and a weighted average of
past tokens is one masked matrix multiplication.** Once you see that, a whole GPT is a few
hundred lines, and model configs, papers and libraries become readable.

## From a loop to a matrix

The lecture builds attention in four versions, each the same computation done better:

1. **Loop.** For each position t, average the vectors of positions 0 to t.
2. **Triangular matrix.** Make a T × T lower-triangular matrix of ones, divide each row by its
   sum, and multiply it by the token matrix. One operation, the same averages.
3. **Masked softmax.** Start from a grid of zeros, fill the upper triangle with minus infinity,
   softmax each row. Still the same averages, but now the zeros can be replaced by scores.
4. **Self-attention.** Fill the grid with query-key dot products, scaled by 1/√head_size. Now
   each token chooses how much each earlier token matters (→ query-key-value-attention).

## Worked example: three tokens

One number per token: x = 2, 4, 9.

The normalized triangular matrix is

```text
[1    0    0  ]
[0.5  0.5  0  ]
[0.33 0.33 0.33]
```

Multiplying it by [2, 4, 9] gives **[2, 3, 5]**: the running averages 2, (2+4)/2 and
(2+4+9)/3. Masked softmax of a zero grid gives exactly the same matrix, because softmax of equal
scores is uniform and e^−∞ = 0.

Now replace row 3's zeros with scores [0, 0, 2]. Softmax gives e^0, e^0, e^2 = 1, 1, 7.39 over a
total of 9.39, so weights **0.11, 0.11, 0.79**, and the output is 0.11·2 + 0.11·4 + 0.79·9 ≈
**7.7**: the third token now listens mostly to itself.

A useful sanity number from the build: with 65 possible characters, an untrained model that
spreads probability evenly has loss −ln(1/65) ≈ **4.17**. That's what the first printed loss
should be close to.

## From one head to a GPT

- **Multi-head attention:** several smaller heads in parallel, outputs concatenated.
- **Feed-forward layer:** each token processes what it gathered (→ mlp-layers-store-facts).
- **Residual connections:** each sub-layer's output is added to its input, giving gradients a
  direct path back through the stack.
- **Layer norm:** each token's vector is normalized before each sub-layer, keeping values in a
  stable range.
- **Scale-up:** more layers, heads, width and context, plus dropout against overfitting.

## Common mistakes

- **Applying the mask after softmax.** Mask first, with minus infinity, so the weights on
  future tokens become exactly 0 and rows still sum to 1.
- **Forgetting the 1/√head_size scale.** Softmax saturates and learning stalls.
- **Leaving the mask on for encoders.** A classifier that sees the whole input shouldn't mask.
- **Confusing batch and time.** Tokens attend along time only; separate examples in a batch
  never mix.
