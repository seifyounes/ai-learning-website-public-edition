task: |
  Prove the collapse on numbers, then break it with one ReLU. Pen and paper is enough; the Python
  check takes two minutes.

  1. Take W1 with rows (1, 2) and (0, 1), b1 = (1, 0), W2 = (1, −1), b2 = 2.
  2. Multiply out W' = W2·W1 and b' = W2·b1 + b2 by hand.
  3. Run x = (2, 3) through both layers, then through W'·x + b'. The answers should match.
  4. Now put a ReLU after the first layer and run x = (−4, 1) both ways. Write down why the
     answers differ.

  ```python
  import numpy as np

  W1 = np.array([[1, 2], [0, 1]]); b1 = np.array([1, 0])
  W2 = np.array([[1, -1]]);        b2 = np.array([2])
  relu = lambda z: np.maximum(0, z)

  for x in (np.array([2, 3]), np.array([-4, 1])):
      two_linear = W2 @ (W1 @ x + b1) + b2
      collapsed = (W2 @ W1) @ x + (W2 @ b1 + b2)
      with_relu = W2 @ relu(W1 @ x + b1) + b2
      print(x, two_linear, collapsed, with_relu)
  ```

  Success: two_linear equals collapsed for both inputs, and with_relu differs for x = (−4, 1),
  with a one-line note on which unit the ReLU switched off.

A layer is a matrix multiply followed by an activation. This lesson asks what happens if you
leave the activation out, and the answer explains why every network you'll meet has one: **a
stack of linear layers is a single linear layer**, however deep you make it.

## The two-line proof

Use the identity as the activation, so each layer passes z straight through:

- Layer 1: a1 = W1·x + b1
- Layer 2: a2 = W2·a1 + b2 = W2·(W1·x + b1) + b2 = (W2·W1)·x + (W2·b1 + b2)

The bracketed pieces are just a new matrix W' and a new bias b'. Two layers became one. Add a
third and it folds in the same way, and so on for any depth. The hidden units still exist in
memory, but they add no power to what the network can represent.

If the output layer uses a sigmoid on top of linear hidden layers, the whole network is no more
expressive than logistic regression: a straight-line boundary pushed through a squashing
function.

## Worked example: collapse it, then break it

Take W1 with rows (1, 2) and (0, 1), b1 = (1, 0), W2 = (1, −1), b2 = 2.

**Fold the layers.** W2·W1 = (1×1 + (−1)×0, 1×2 + (−1)×1) = (1, 1). The bias is
W2·b1 + b2 = (1×1 + (−1)×0) + 2 = 3. So the two layers equal **x₁ + x₂ + 3**.

**Check on x = (2, 3).** Layer 1: (2 + 6 + 1, 0 + 3 + 0) = (9, 3). Layer 2: 9 − 3 + 2 = 8.
The folded version: 2 + 3 + 3 = 8. Same answer, as promised.

**Now add a ReLU after layer 1, with x = (−4, 1).** Layer 1 gives (−4 + 2 + 1, 1) = (−1, 1),
and ReLU turns it into (0, 1). Layer 2: 0 − 1 + 2 = **1**. The folded linear formula says
−4 + 1 + 3 = **0**. The ReLU switched off the first unit for this input only, which is
something no single matrix can do: it applies different arithmetic in different regions of
the input. That region-by-region behaviour is what lets networks bend their decision
boundaries.

## The one place linear is fine

At the **output** of a regression model, where the target is a real number such as a price or a
duration, a linear activation is the natural choice, because the output must be able to take any
value. If the target can't be negative, a ReLU output also works. The hidden layers still get a
nonlinearity. Linear hidden layers are rare and come up in special cases such as compression.

## Common mistakes

- **Forgetting the activation in hand-written layers.** Code runs, loss falls a little, and the
  model quietly behaves like linear regression.
- **Thinking the output sigmoid is enough.** One nonlinearity at the end doesn't help the hidden
  layers; it has to sit between them.
- **Adding layers to fix underfitting in a linear model.** Without activations, depth changes
  nothing; add the nonlinearity first.

## Where you'll see it in AI

- **Every transformer block** has an MLP with a nonlinear activation between its two matrices,
  and attention itself bends its scores through a softmax (→ transformers-attention).
- **LoRA** uses the collapse on purpose: two thin matrices with nothing between them form one
  low-rank update that can be merged into the weights (→ fine-tuning-fundamentals).
- **Linear probes** on embeddings test what a single matrix can read out of a representation;
  their limits are exactly the limits shown here (→ embeddings-vector-databases).
