task: |
  **Backprop a two-layer chain by hand, then check every number (30 minutes).**

  A chain of two sigmoid neurons: `a1 = sigmoid(w1·x + b1)`, `a2 = sigmoid(w2·a1 + b2)`,
  cost `(a2 − y)²`, with x = 1, y = 1, w1 = 0.8, b1 = 0.1, w2 = 2.0, b2 = −0.5.

  1. Write the chain-rule product for ∂C/∂w2 and for ∂C/∂w1 (the second one goes through a2,
     z2, a1 and z1). Use sigmoid'(z) = a(1 − a).
  2. Run the forward pass, then the backward pass, and check each gradient with a nudge:

     ```python
     import math

     def sig(z):
         return 1 / (1 + math.exp(-z))

     def cost(w1, b1, w2, b2, x=1.0, y=1.0):
         return (sig(w2 * sig(w1 * x + b1) + b2) - y) ** 2

     w1, b1, w2, b2, x, y = 0.8, 0.1, 2.0, -0.5, 1.0, 1.0
     a1 = sig(w1 * x + b1)
     a2 = sig(w2 * a1 + b2)

     dC_dz2 = 2 * (a2 - y) * a2 * (1 - a2)       # last layer
     dC_dw2, dC_db2 = dC_dz2 * a1, dC_dz2
     dC_dz1 = dC_dz2 * w2 * a1 * (1 - a1)        # one layer back
     dC_dw1, dC_db1 = dC_dz1 * x, dC_dz1

     e, p = 1e-6, [w1, b1, w2, b2]
     for i, mine in enumerate([dC_dw1, dC_db1, dC_dw2, dC_db2]):
         up, down = p.copy(), p.copy()
         up[i] += e
         down[i] -= e
         print(f"chain rule {mine:.6f}  nudge {(cost(*up) - cost(*down)) / (2 * e):.6f}")
     ```

  3. Compare the size of the first-layer gradients with the second-layer ones and write one
     sentence on why they're smaller.

  Success: both columns match: about −0.0476 for w1 and b1, −0.0824 for w2 and −0.1159 for b2;
  and you can point to the extra sigmoid-slope factor (at most 0.25) that shrinks the first

The one idea of this lecture: **backpropagation is the chain rule written out for a network,
starting at the cost and working backwards one layer at a time.** Gradient descent needs the
partial derivative of the cost for every weight and bias. Backprop gets all of them in one
backward sweep, reusing the values the forward pass already computed, so the whole gradient
costs about as much as one more forward pass.

## The smallest network that shows everything

Take a chain with one neuron per layer and focus on the last connection. The previous neuron's
activation is `a(L−1)`; the last neuron computes

```text
z = w·a(L−1) + b
a(L) = σ(z)
C = (a(L) − y)²
```

A nudge to `w` moves `z`, which moves `a(L)`, which moves `C`. The chain rule multiplies the
three local rates:

```text
∂C/∂w = ∂z/∂w · ∂a/∂z · ∂C/∂a
      = a(L−1) · σ'(z) · 2(a(L) − y)
```

Each factor has a meaning. `2(a(L) − y)`: a big miss makes a big gradient. `σ'(z)`: the
activation's slope at this point. `a(L−1)`: a weight matters more when the neuron feeding it is
active ("fire together, wire together"). For the bias, swap the first factor for `∂z/∂b = 1`.
For the previous activation, swap it for `∂z/∂a(L−1) = w`, and that number is what you carry one
layer back to repeat the process.

## Worked example with real numbers

Let `a(L−1) = 0.5`, `w = 2`, `b = −0.5`, target `y = 1`, sigmoid activation.

| quantity | value |
|---|---|
| z = 2·0.5 − 0.5 | 0.5 |
| a(L) = σ(0.5) | 0.6225 |
| C = (0.6225 − 1)² | 0.1425 |
| ∂C/∂a = 2(a − y) | −0.7551 |
| σ'(z) = a(1 − a) | 0.2350 |
| ∂C/∂z | −0.1774 |
| ∂C/∂w = 0.5 × ∂C/∂z | −0.0887 |
| ∂C/∂b = 1 × ∂C/∂z | −0.1774 |
| ∂C/∂a(L−1) = 2 × ∂C/∂z | −0.3549 |

A nudge check (move `w` by ±0.000001 and divide) gives −0.0887 too. The last line is the
"propagate backwards" part: the previous layer receives −0.3549 and runs the same steps for its
own weight and bias.

## Real layers: sum over paths

With several neurons per layer, the weights get two indices and the cost sums over the output
neurons, but the expression for one weight looks the same. What changes is the gradient for an
activation in layer L−1: that neuron feeds *every* neuron in layer L, so it affects the cost by
several paths, and you **add** the contributions. Then repeat for the layer before. Finally, the
cost is an average over training examples, so the real gradient averages these per-example
values.

## Common mistakes

- **Forgetting the sum over paths** when a neuron feeds several others.
- **Using a fresh forward pass's values in the backward pass.** Backprop must use the values
  from the same forward pass that produced the loss.
- **Calling backprop the optimizer.** It only computes the gradient; gradient descent, momentum
  or Adam decide the step.
- **Ignoring the slope factors.** Each sigmoid adds a factor of at most 0.25, which is how
  gradients vanish in deep stacks.

## Where you'll see it in AI

- **Every framework's autograd** (PyTorch, JAX, TensorFlow) runs this for you on any network.
- **Training memory:** stored activations and per-weight gradients (→ adam-optimizer adds the
  optimizer's share).
- **Fine-tuning with adapters:** gradients flow through frozen layers to reach small trainable
  ones (→ fine-tuning-fundamentals).
- **Architecture choices** such as ReLU activations and residual connections exist partly to
  keep these products from vanishing (→ neural-networks, → transformers-attention).
