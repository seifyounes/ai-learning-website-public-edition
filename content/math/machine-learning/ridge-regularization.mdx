task: |
  Watch a penalty rescue an overfit model. The code makes 30 training rows with 20 inputs, of
  which only 3 matter, then fits ridge regression at several strengths and scores each on 200
  held-out rows. Run it in a free Google Colab notebook or any Python with NumPy:

  ```python
  import numpy as np

  rng = np.random.default_rng(1)
  n_train, n_test, n_features = 30, 200, 20
  true_w = np.zeros(n_features)
  true_w[:3] = [3.0, -2.0, 1.5]                 # only 3 of the 20 inputs matter

  X = rng.normal(size=(n_train + n_test, n_features))
  y = X @ true_w + rng.normal(0, 2.0, n_train + n_test)
  X_tr, y_tr, X_te, y_te = X[:n_train], y[:n_train], X[n_train:], y[n_train:]

  def ridge_fit(X, y, lam):
      x_mean, y_mean = X.mean(axis=0), y.mean()
      Xc, yc = X - x_mean, y - y_mean           # the intercept is not penalised
      w = np.linalg.solve(Xc.T @ Xc + lam * np.eye(X.shape[1]), Xc.T @ yc)
      return w, y_mean - x_mean @ w

  for lam in [0, 1, 5, 20, 100, 1000]:
      w, b = ridge_fit(X_tr, y_tr, lam)
      mse = lambda X, y: np.mean((X @ w + b - y) ** 2)
      print(f"lambda {lam:>4}: train {mse(X_tr, y_tr):5.2f}  test {mse(X_te, y_te):5.2f}  "
            f"size of weights {np.sum(w ** 2):5.2f}")
  ```

An overfit model is too sensitive to the training data: small quirks in the examples swing its
predictions. **Regularization fixes that by adding a penalty to the loss for large weights, so
the model accepts a slightly worse fit to the training data in exchange for predictions that
vary much less.** Ridge regression is the cleanest version, and its idea survives in nearly
every large model as weight decay.

## The penalty

Least squares minimises the sum of squared residuals. Ridge minimises:

```text
SSR + λ × (sum of squared weights)
```

The intercept is left out: it only sets the average level and doesn't make predictions
sensitive to any input. **λ (lambda)** sets how much the penalty counts. At λ = 0 you get plain
least squares; as λ grows, the weights shrink toward zero and the predictions flatten toward the
average. A smaller weight means the prediction moves less when its input moves, which is
exactly what "lower variance" means in practice.

You can't know λ in advance, so you choose it with → cross-validation-folds: try a range, keep
the value with the best cross-validated error.

## Worked example: two training points

Training data: (2, 3) and (4, 6). Testing data: (1, 3.2), (3, 4.2), (5, 5.4). Use λ = 1.

- **Least squares** passes through both points: y = 1.5x. Training SSR = 0, penalty =
  1 × 1.5² = 2.25, total **2.25**.
- **Ridge** gives slope 1.0 (centred formula: 3 / (2 + λ)), line y = 1.5 + 1.0x. Its
  predictions 3.5 and 5.5 miss by 0.5 each: SSR = 0.5, penalty = 1 × 1.0² = 1, total **1.5**.
  Ridge's total is lower, so it wins the penalised contest.

Now the testing points. Least squares predicts 1.5, 4.5, 7.5: SSR = 2.89 + 0.09 + 4.41 =
**7.39**. Ridge predicts 2.5, 4.5, 6.5: SSR = 0.49 + 0.09 + 1.21 = **1.79**. Giving up a perfect
training fit cut the test error by about three quarters. With λ = 2 the slope would be 0.75; at
very large λ it approaches 0, a flat line at the average, which is too much bias.

## Common mistakes

- **Not standardizing inputs.** The penalty is on weight size, which depends on units; rescale
  inputs so the penalty treats them fairly.
- **Choosing λ on the test set.** Use cross-validation; the test set is for the final check.
- **Penalising the intercept.** It shifts every prediction equally and should stay free.
- **Expecting feature selection.** Ridge shrinks weights but rarely to exactly zero. Lasso, its
  sibling with an absolute-value penalty, can zero them out.

## Where you'll see it in AI

- **Weight decay** in neural network training and fine-tuning applies the same pull toward
  small weights at every step (→ neural-networks, → fine-tuning-fundamentals).
- **Over-parameterised models**, with far more weights than training examples, are normal in
  deep learning; penalties and other regularizers help them generalize instead of memorizing.
- **Regularized logistic regression** on embeddings is a standard, strong text-classification
  baseline (→ embeddings-vector-databases).
- **Trees** have their own variance controls: limits on depth and leaf size, then averaging
  many trees (→ decision-trees-gini, → random-forests-bagging).
