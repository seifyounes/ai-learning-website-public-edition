# Independent review rubric — AI Learning (public edition)

The reviewer is an independent agent with **no project context**. It judges the running site
the way a demanding member of the public would: a student, developer or professional who wants
to learn AI and has never heard of the author. Ship bar: **every criterion ≥ 9/10**. Below that,
apply the reviewer's fixes and run a fresh review.

Score each criterion 1–10 (decimals allowed), with evidence (page URLs, lesson slugs, quotes)
and the concrete fixes that would raise it.

| # | Criterion | What a 9+ looks like |
|---|---|---|
| 1 | Content quality & accuracy | Lessons teach correctly, in depth, current for 2026; clear explanations; no filler. |
| 2 | Relevance for any learner | Nothing reads as written for one specific person; apply-it, toolkit and tasks are concrete and doable for students, developers and professionals. |
| 3 | Learning design | Clear progression, prerequisites signposted, practice and self-checks that test understanding, a coherent path from beginner to advanced. |
| 4 | Onboarding & orientation | A first-time visitor understands what this is, who it's for and where to start within 30 seconds. |
| 5 | Navigation & findability | Easy to move between sections, pillars and lessons; search works; never lost; previous/next flow. |
| 6 | Interactive features | Progress, recap, self-check, quizzes, notes, checklist work reliably and feel worth using. |
| 7 | Visual design & readability | Distinctive, coherent, comfortable to read for long sessions; hierarchy is obvious. |
| 8 | Mobile experience | Fully usable at 320–390px: no sideways scroll, tappable targets, readable text. |
| 9 | Accessibility | Semantic structure, keyboard use, focus visibility, contrast, labels, reduced motion. |
| 10 | Trust & credibility | Sources and creators credited, honest about how content is made, review dates, privacy stated, no hype or unverifiable claims. |
| 11 | Technical polish | No errors or broken pages, fast, good metadata/share cards, sensible 404, no leftovers from a private build. |

Overall = the mean, but the bar is per criterion.
